What is Nmap?

Nmap (Network Mapper) is a free, open-source tool used for network discovery and security auditing. Think of it like a digital "knock and check"—it went to a computer on a network and asked, "What doors (ports) do you have open?"

It has dedicated options to deal with:

  • Host Discovery
  • Scan Techniques
  • Port Specification and Scan Order
  • Service/Version Detection
  • Script Scan
  • OS Detection
  • Timing and Performance
  • Firewall/IDS evasion and spoofing

Commands and it’s options:

The -sL option performs a network scan that lists all possible hosts within a given subnet. For example, when used with a /24 subnet mask, it will generate a list of all 255 valid IP addresses in that range.

-sn (Ping Scan)

Command: nmap -sn <TARGET>
Example: nmap -sn 192.168.0.0/24

Output:
└─$ nmap -sn 192.168.71.0/28
Starting Nmap 7.99 ( https://nmap.org ) at 2026-09-05 18:09 -0400
Nmap scan report for 192.168.71.1
Host is up (0.00043s latency).
MAC Address: 00:50:56:C0:00:08 (VMware)
Nmap scan report for 192.168.71.2
Host is up (0.00058s latency).
MAC Address: 00:50:56:E3:8E:42 (VMware)
Nmap done: 16 IP addresses (2 hosts up) scanned in 3.94 seconds

The -sn option performs a host discovery scan that checks which devices are actively online within a given subnet. Unlike -sL, which merely lists all possible IP addresses, -sn actively sends probes to determine which hosts are actually up and responding. For each live device discovered, it also reveals additional information such as the MAC address and the vendor or brand (e.g., Dell, Apple, Cisco) derived from the MAC address's OUI (Organizationally Unique Identifier). For example, when used on a /24 subnet, it will identify which of the 255 possible IPs are currently active and provide their MAC and vendor details.

The -sW option performs a Windows-style TCP scan that sends ACK packets to identify open ports based on RST responses.

-sU (UDP Scan)

The -sU option performs a UDP scan that sends UDP packets to determine which UDP ports are open on the target.

The -p- option scans all 65535 TCP ports on the target instead of the default top 1000 ports.

— — top-ports (Most Common Ports)

Command: nmap --top-ports <Number> <Target>
Example: nmap --top-ports 100 192.168.71.132

Output:
PORT    STATE SERVICE

22/tcp  open  ssh
23/tcp  open  telnet
25/tcp  open  smtp
53/tcp  open  domain
80/tcp  open  http

The --top-ports option scans the specified number of most commonly encountered ports. It provides a faster alternative to scanning every port.

The -sC option runs Nmap's default NSE (Nmap Scripting Engine) scripts against the target. These scripts can gather additional information about services and identify common configuration issues.
